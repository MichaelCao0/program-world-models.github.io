# Program World Model homepage

A standalone, buildless research landing page for the Program World Model workstream.

## Preview

```bash
python3 -m http.server 4173 --directory .
```

Open <http://127.0.0.1:4173/>.

The page is intentionally static. It links the survey catalogue, PWM-Arena, and a reserved method track without inventing a paper title, benchmark result, or release date for the method work.
