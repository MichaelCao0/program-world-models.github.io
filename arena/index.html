P · D · R Three-Track Decoupled Evaluation

Hybrid world models separate a symbolic rule/state engine from a neural renderer, while code world models output state without pixels and pixel simulators output video without explicit state. Decoupling around pwm-state-v1 attributes semantic failures (P+D), materialization failures (R), and closed-loop drift (E / P→D→R).

UNIFIED CONTRACT pwm-state-v1 · 6-step tick · obs routing

State Contract, 6-Step Tick Order & Field Denominator Routing

Excluding meta-headers (tick, schema_version, random_stream) and routing hidden/unbound fields out of R prevents unobservable states from inflating or distorting visual failure counts.

Mandatory 6-Step Tick Execution Order step(s_t, op_t)
  1. 01
    Apply Meta-Edits

    Execute set_rule, add_rule, revoke(rule_id, cancel_pending), set_param, schedule(id, at, do), and cancel(id | rule_id).

  2. 02
    Fire Due Pending Events

    Drain pending[] entries where e.at === tick in ascending event id order before agent actions run.

  3. 03
    Apply Agent Actions

    Apply closed typed actions (activate, use, attack, place, insert_item, enter_zone, pan) and record entity state deltas.

  4. 04
    Resolve Triggered Active Rules

    Evaluate rules with status === 'active' inside [active_from, expires_at] in descending priority, tie-breaking by higher version, then insertion order.

  5. 05
    Consume One-Shot Rules

    Transition any fired rule with once: true to status = 'consumed' so subsequent triggers are deterministic no-ops.

  6. 06
    Advance Logical Tick & Log

    Append causal trace entry to log[] and advance tick (meta-header excluded from accuracy denominator).
